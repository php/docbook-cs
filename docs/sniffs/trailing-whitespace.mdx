# TrailingWhitespaceSniff

`DocbookCS.TrailingWhitespace`

Detects trailing whitespace (spaces or tabs) at the end of a line. Each
violation is reported per line.

:::tip Auto-fixable
This sniff ships a fixer — run with [`--fix`](/fixing) to remove trailing
whitespace automatically.
:::
