# MixedIndentationSniff

`DocbookCS.MixedIndentation`

Detects mixed indentation: spaces followed by tabs, or tabs followed by
spaces, at the start of a line. Each violation is reported per line.

:::tip Auto-fixable
This sniff ships a fixer — run with [`--fix`](/fixing) to replace the tabs
in the affected indentation with spaces automatically.
:::
